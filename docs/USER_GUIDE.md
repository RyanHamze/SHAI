# Using SHAI

## Setup

Launch SHAI Setup from Ubuntu's application menu. Review the proposed
configuration and optional architecture choices before approval. System changes
run visibly through a terminal with Ubuntu's normal authentication. Back up
your system first; application removal and service changes can affect use.

## SHAPP

Use the recommended, optional and installed lists to select supported apps.
Review pending installations/removals before Apply. The update options perform
explicit maintenance; online package downloads require internet access.
Ubuntu's app manager remains available for applications SHAI protects or does
not manage. Advanced container mode needs additional configuration.

## SHEALTH

View resources, services and network observations. Estimates, including energy
figures, are not exact meter readings unless backed by measured data. A service
being detected does not prove every device or integration works.

## AIA

Manage supported local models and integration configuration. Online model/tool
downloads need the online-install permission and separate approval. Model
quality and performance depend on hardware and the selected model. User-added
notes and context are reference information, not model training or permission
to run commands. Review supported control requests before approving them.

## Privacy and support

Keep passwords, tokens and private configuration out of notes and public
reports. Review logs locally and redact sensitive information before sharing.
The web proxy toggle is not a host-wide air gap; optional software can have its
own network behavior. Current capabilities depend on the installed release.

See [installation](INSTALL_FROM_GITHUB.md), [security](../SECURITY.md), and
